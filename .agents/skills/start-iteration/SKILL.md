# Skill: Start Iteration

## When to Use
At the beginning of a new unit of work (feature, resource module, refactor, bug fix).

## Instructions
1. Read existing iterations in `docs/implementation/` to get the next number
2. Create `docs/implementation/NNN-iteration-title.md` with these sections:
   - **Date**: Today's date
   - **Status**: In Progress
   - **Goal**: One sentence describing the objective
   - **What We Set Out to Build**: Bullet list of planned deliverables
3. Use TodoWrite to track the steps within the current session
4. Run `make check` to verify the starting state is green before making changes
